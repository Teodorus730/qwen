# Идея

Идея заключается в способе сравненияя 2 моделей, проверке функциональной эквивалентности на выборке

1. Описать ллм как функцию с конечномерным входом и конечномерным выходом. 

$$ LLM = f(x); \;\; f: \mathbb{R}^n \to \mathbb{R}^m $$

Примеры: 

На вход: 

- Эмбеддинг текста из любого энкодера (смысл то сохраняется)

- N айдишников токенов, N фиксированное (хоть единица). Могут быть проблемы с тем что пространство айдишников не содержит информации о тексте + не метрическое

На выход:

- Полное распределение на следующий токен (может быть слишком большое - дорого)

- Аргмакс распределения (либо айдишник, либо эмбед)

- Для Multiple-Choice Benchmarks (бенчмарки с множественным выбором) или MCQ-тестов пересчитать софтмакс распределения по логитам токенов ответов (A B C D), может быть проблема с равными или около нулевыми вероятностями

- Вычислять лосс по всему распределеню (нужен правильный ответ - таргет)

2. Взять некоторое множество точек в пространстве входов и построить гауссовские процессы функций для 2 и более моделей

3. Сравнить гауссовкие процессы между собой (GP - это в первую очередь распределение, их можно сравнивать разными способами)

# Возможные проблемы

1. Вычислительная стоимость. Не особо понятно какие брать точки для построения GP, их может быть многовато

2. В рамках идеи отбрасывается авторегрессионность, ЛЛМ рассматривается как обычная функция. По идее это не большая проблема, т. к. на каждой итерации прогоняется та же самая функция (эмбед входа -> распределение на выход)

3. Может быть проблема с соответствием между входом ЛЛМ и эмбедом из обычной модельки энкодера (с одной стороны семантика текста учитывается, с другой стороны мы опускаем эмбеддинг слой исследуемых моделей)
