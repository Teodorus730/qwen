# Continued pretraining на одной GPU Vast.ai

Эксперименты разделены по фактическим GPU и больше не смешивают завершённый
запуск с подготовкой следующего.

| Папка | Статус | Назначение |
|---|---|---|
| [`rtx_5070_ti_16gb/`](rtx_5070_ti_16gb/README.md) | завершён | Исходники запуска, upload ZIP, полный архив, метрики, графики и интерпретация эксперимента от 29 июля 2026 года |
| [`rtx_5090_32gb/`](rtx_5090_32gb/README.md) | завершён | Bundle, выгруженные результаты и [подробный сравнительный отчёт](rtx_5090_32gb/REPORT.md) по запуску от 1 августа 2026 года |

## Какой файл куда загружать

- Для воспроизведения старого запуска:
  `rtx_5070_ti_16gb/vast_ai_single_gpu_upload.zip`
- Для воспроизведения запуска на RTX 5090:
  `rtx_5090_32gb/rtx_5090_32gb_upload.zip`

ZIP-файлы и выгруженные checkpoints остаются локальными и исключены из Git.
Исходники, конфигурации, инструкции, метрики и отчёты хранятся в репозитории.
