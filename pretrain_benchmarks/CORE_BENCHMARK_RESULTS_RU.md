# Базовая оценка Qwen3.5-0.8B-Base

## Цель

Мы зафиксировали отправную точку официальной Base-модели
`Qwen/Qwen3.5-0.8B-Base`, чтобы затем честно сравнивать с нашими
предобученными, сжатыми и промежуточными моделями на неизменном протоколе.

## Что проверяли

| Бенчмарк | Что примерно измеряет | Тип |
|---|---|---|
| WikiText | Предсказание текста на английском корпусе | Внутренняя LM-оценка |
| Wikipedia EN/ZH/RU | Вероятность фиксированных текстов на трёх языках | Внутренняя LM-оценка |
| LAMBADA | Предсказание последнего слова в контексте | Диагностика возможностей Base-модели |
| HellaSwag | Выбор правдоподобного продолжения | Диагностика возможностей Base-модели |
| PIQA | Выбор практического физического решения | Диагностика возможностей Base-модели |
| ARC-Easy | Вопросы школьного уровня | Диагностика возможностей Base-модели |

Последние четыре задачи не требуют instruction tuning и не являются
«чистыми» метриками предобучения: они дополняют языковые метрики.

## Протокол

- Модель: `Qwen/Qwen3.5-0.8B-Base`;
  SHA `dc7cdfe2ee4154fa7e30f5b51ca41bfa40174e68`.
- lm-eval задачи запущены полностью, без `--limit`, в zero-shot режиме с
  seed 42.
- Оборудование: Intel Arc A770 16 GB, XPU, BF16.
- Для Wikipedia использован закреплённый корпус EN/ZH/RU: около 1 MiB исходных
  UTF-8 байт на язык.

## Итоговые результаты

### WikiText и capability diagnostics

| Бенчмарк | Метрика | Результат |
|---|---|---:|
| WikiText | bits per byte | 0.7975 |
| WikiText | byte perplexity | 1.7381 |
| WikiText | word perplexity | 19.2196 |
| LAMBADA OpenAI | acc | 0.5077 |
| LAMBADA OpenAI | perplexity | 11.6661 |
| HellaSwag | acc / acc_norm | 0.4201 / 0.5484 |
| PIQA | acc / acc_norm | 0.7018 / 0.7155 |
| ARC-Easy | acc / acc_norm | 0.7050 / 0.6747 |

`acc` — обычная точность выбора ответа. `acc_norm` — точность после
нормализации по длине ответа, поэтому эти две величины не нужно смешивать.

### Multilingual Wikipedia

BPB (bits per byte, биты на UTF-8 байт) — основная нормализованная языковая
метрика в этом протоколе. PPL (perplexity, перплексия) приведена как
дополнительная метрика.

| Язык | BPB | PPL |
|---|---:|---:|
| Английский (EN) | 0.8722 | 11.2486 |
| Китайский (ZH) | 1.1715 | 20.1050 |
| Русский (RU) | 0.5583 | 8.8706 |

### Multilingual / knowledge diagnostics

| Бенчмарк | Охват | Метрика | Результат |
|---|---|---|---:|
| C-Eval validation | 1 346 вопросов | acc / acc_norm | 0.5498 / 0.5498 |
| MMMLU full | 196 588 вопросов, 14 локалей, 57 предметных областей | acc / acc_norm | 0.4017 / 0.4017 |

C-Eval и MMMLU запускались для базовой `Qwen3.5-0.8B-Base` в zero-shot
режиме. MMMLU посчитан на полном наборе, а не на 5% подмножестве: итоговая
точность составляет 40,17% (78 977 верных ответов из 196 588). Из-за
вычислительной стоимости набор был оценён двумя непересекающимися частями,
которые вместе в точности покрывают весь закреплённый тестовый набор.

## Как интерпретировать

Эти числа будут контрольной точкой для следующих моделей. BPB разумно
сравнивать между моделями внутри одного языка на одном и том же фиксированном
корпусе. PPL зависит от токенизатора, поэтому напрямую сравнивать её между
разными токенизаторами нельзя. Разницу между EN, ZH и RU нельзя превращать в
рейтинг того, какой язык модель «знает лучше»: корпуса и токенизация разные.

## Воспроизводимость

SHA модели, Git provenance, окружение и компактные результаты сохранены в
репозитории. Wikipedia закреплена конкретной revision; наборы текстов
закреплены canonical manifests и SHA. Будущие модели должны оцениваться на
тех же manifests, а не на новой случайной выборке.
